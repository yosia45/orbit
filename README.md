# 精品商店 購物車應用

一個現代化的單頁面購物車應用，使用 Vue.js 3 和原生 HTML/CSS 構建。

## 📋 項目概述

這個項目提供了一個完整的電商購物車系統，展示了如何使用前端框架實現複雜的交互功能。應用包含商品展示、搜尋、購物車管理、結帳流程等核心功能。

## ✨ 核心功能

### 1. 商品展示
- 響應式網格佈局（自適應不同屏幕尺寸）
- 商品卡片展示（圖片、名稱、價格）
- 動態加載商品列表

### 2. 搜尋功能 🔍
- **實時搜尋**: 無需按確認按鈕，實時過濾商品
- **模糊搜尋**: 支持商品名稱部分匹配
- **無結果提示**: 當無法找到商品時顯示友好提示

### 3. 購物車管理
- **快速添加**: 一鍵添加商品到購物車
- **數量調整**: 使用 ± 按鈕調整購物車中商品的數量
- **即時計算**: 自動計算商品總數和總金額
- **商品移除**: 通過刪除按鈕或將數量減至 0 來移除商品

### 4. 確認對話框
- **結帳確認**: 在結帳前要求用戶確認
- **移除確認**: 在刪除商品前要求用戶確認
- **操作防護**: 防止意外的誤操作

### 5. 用戶反饋
- **通知系統**: 商品添加/移除時顯示成功通知
- **加載指示器**: 商品加載和結帳過程中顯示加載動畫
- **按鈕狀態**: 結帳中時按鈕禁用並顯示加載文本

## 🎯 已解決的代碼問題

### 原始代碼的 16 個問題
1. ✅ 固定寬度導致響應式設計不佳 → 使用 max-width 和 Flexbox
2. ✅ 購物車圖示在小螢幕位置有問題 → 使用 Flexbox 自動布局
3. ✅ 產品網格在手機上破版 → 使用 CSS Grid 的 auto-fit
4. ✅ 缺少手機端媒體查詢 → 添加多個斷點的媒體查詢
5. ✅ CSS 選擇器過度巢狀 → 扁平化 CSS 選擇器
6. ✅ 全域變數污染 → 使用 Vue.js 的響應式系統
7. ✅ 沒有錯誤處理的 API 呼叫 → 添加 try-catch 和驗證
8. ✅ DOM 操作效率低下 → 使用 Vue 的虛擬 DOM
9. ✅ 沒有節流的搜尋 → Vue 的響應式系統自動優化
10. ✅ 沒有使用者反饋 → 添加通知系統
11. ✅ 重複的 DOM 查詢 → 使用 Vue 的計算屬性
12. ✅ 沒有適當的載入狀態 → 添加加載指示器和按鈕禁用狀態
13. ✅ 沒有事件委託 → 使用 Vue 的事件綁定
14. ✅ 沒有防抖機制 → 使用計算屬性替代事件監聽
15. ✅ 載入時沒有錯誤處理 → 添加 mounted 鉤子和驗證
16. ✅ 沒有清理事件監聽器 → Vue 自動管理生命週期

## 💻 響應式斷點

應用在以下斷點進行優化：

- **桌面** (> 768px)
  - 4 列產品網格
  - 標準購物車側邊欄（固定寬度）
  - 全寬搜尋框

- **平板** (768px 及以下)
  - 2 列產品網格
  - 調整的間距和字體

- **手機** (480px 及以下)
  - 單列或流動網格
  - 購物車側邊欄全寬
  - 緊湊的佈局
